UPDATE THIS WEBSITE (Windows + GitHub Desktop)

1. Extract ZIP and open the folder containing index.html.
2. GitHub Desktop > Repository > Show in Explorer.
3. Copy all items INSIDE the extracted folder into the GitHub repository folder.
4. Choose Replace for files with the same name; NEVER delete .git, .github or CNAME.
5. Double-click index.html locally: verify portrait and research media proportions.
6. Return to GitHub Desktop > Commit to main > Push origin.
7. Refresh https://manojkumargupta2312.github.io/ with Ctrl + Shift + R after publication.
