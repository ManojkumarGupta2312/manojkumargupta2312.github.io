UPDATE THIS WEBSITE — QUICK STEPS (WINDOWS)

FIRST: Extract this ZIP. Inside the website folder, find index.html, assets and files.

TO CHANGE 3 MEDIA FILES (optional):
1. Profile image: assets/images/profile-photo.jpg (JPEG)
2. TBL photograph: assets/images/tbl-facility.jpg (JPEG)
3. TBL video: assets/media/tbl-voronoi.mp4 (MP4 / H.264)
4. Optional video poster: assets/images/tbl-video-poster.jpg
Replace these files using exactly the same filenames. No HTML editing needed.

TO UPDATE GITHUB:
1. Open GitHub Desktop → select manojkumargupta2312.github.io.
2. Repository → Show in Explorer.
3. In repository root, replace website files with ALL CONTENTS of this extracted folder.
   Preserve hidden .git and any .github, CNAME, .nojekyll files.
   index.html must be in the repository ROOT (not another nested folder).
4. GitHub Desktop → Commit to main → Push origin.
5. Check GitHub Actions / Settings → Pages, then open:
   https://manojkumargupta2312.github.io/
6. Refresh browser with Ctrl + Shift + R after deployment.

If you already deleted old files: Git keeps committed history; deleting old files locally does not automatically delete your ability to recover them.
